# TG Media Downloader

Расширение для Chrome/Edge для [Telegram Web A](https://web.telegram.org/a/):

- **Скачивание**: кнопка «⬇ Скачать» под фото, видео, кружочками и голосовыми, «⬇ Скачать все» под альбомами. Работает и в каналах, где пересылка и сохранение запрещены.
- **Пересылка от своего имени**: кнопка «↪ Переслать» заново загружает пост в выбранный канал, группу или личку, как будто ты отправил его сам. Без плашки «Переслано из», тоже работает для каналов с запретом пересылки.

## Установка

1. Скачай этот репозиторий: кнопка **Code → Download ZIP**, распакуй в любую папку
2. Открой в браузере `chrome://extensions/` (или `edge://extensions/`)
3. Включи **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажми **«Загрузить распакованное»** и выбери распакованную папку
5. Открой [web.telegram.org/a/](https://web.telegram.org/a/) — под медиа появятся кнопки. Под голосовым кнопки появляются после первого нажатия ▶

## Обновление

Если скачивал ZIP:

1. Скачай новый ZIP: **Code → Download ZIP**
2. Распакуй его и замени файлы в той же папке, откуда расширение загружено в браузер (папку не переименовывай и не перемещай, иначе браузер её потеряет)
3. Открой `chrome://extensions/` (или `edge://extensions/`) и нажми **↻** (иконка обновления) на карточке TG Media Downloader
4. Перезагрузи вкладку Telegram (F5)

Если клонировал через git — в папке расширения выполни:

```bash
git pull
```

затем шаги 3–4 выше.

Без шагов 3–4 браузер продолжит работать со старой версией, даже если файлы уже новые.

## Пересылка постов

Нажми «↪ Переслать» под медиа — откроется окно выбора чата. Вверху «Недавние» (последние 5 чатов, куда пересылал), ниже все чаты из списка диалогов. В поиске можно ввести название или `@username` и нажать Enter. Каналы показываются только те, где ты админ с правом публикации.

Что пересылается:

| Пост | Как придёт |
|---|---|
| Кружок | Кружком |
| Фото, видео | Фото / видео с текстом поста в подписи |
| Голосовое | Голосовым с текстом поста в подписи |
| Альбом | Альбомом (кнопка «↪ Переслать альбом» под ним) |
| Только текст | Текстом с сохранённым форматированием (кнопка появляется в углу сообщения при наведении) |

Особенности:

- Если текст длиннее 1024 символов (лимит подписи без Premium), сначала придёт медиа, следом текст отдельным сообщением.
- Кнопки под голосовым появляются после первого нажатия ▶ на нём.
- Если видео в альбоме ещё не подгрузилось, кнопка напишет «Видео не загружено» — прокрути до него или запусти, потом нажми ещё раз.
- Telegram Web должен быть открыт **в одной вкладке**. Если открыто несколько, пересылка работает только в одной из них, в остальных будет ошибка «API TG не найден».
- Ход отправки виден прямо на кнопке. Если Telegram минуту не отвечает, кнопка покажет «TG не отвечает (таймаут)» — попробуй ещё раз.
- Пересылка использует внутренние механизмы Telegram Web, поэтому после его обновлений может сломаться. Подробный лог — в консоли браузера (F12 → Console), строки `[TG-FWD]`.

## Отправка скачанных голосовых как голосовых (send-voice)

Для пересылки в Telegram удобнее кнопка «↪ Переслать» (см. выше). Этот скрипт нужен, если голосовое уже скачано файлом.

Официальные приложения Telegram отправляют готовый `.ogg` как аудиофайл, а не как голосовое. Настоящее голосовое можно отправить только через бота, и это делает скрипт из папки `send-voice`:

- **Windows**: `send-voice.bat` (на него перетаскивают файлы)
- **macOS и Linux**: `send-voice.sh` (запускается из терминала, нужен только `curl`, он есть в системе из коробки)

Оба скрипта берут настройки из одного файла `send-voice/config.txt`.

### 1. Создай бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Придумай боту имя, потом username, который заканчивается на `bot` (например `my_voice_sender_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Сохрани его и никому не показывай: по токену любой может управлять ботом.
4. Найди своего бота по username и нажми **Start** (или отправь `/start`). Без этого бот не сможет тебе писать.

### 2. Узнай свой chat_id

Открой [@userinfobot](https://t.me/userinfobot) и нажми **Start**. Он пришлёт твой `Id`, например `128697674`.

### 3. Разреши боту присылать голосовые

Если в настройках приватности у тебя ограничены голосовые сообщения (в Premium есть такая настройка), бот получит ошибку `VOICE_MESSAGES_FORBIDDEN`. Добавь бота в исключения:

**Настройки → Конфиденциальность → Голосовые сообщения → Всегда разрешать → добавь своего бота.**

### 4. Настрой скрипт

1. Создай файл `config.txt` первым запуском скрипта, он появится рядом со скриптом:
   - **Windows**: перетащи любой `.ogg` файл на `send-voice\send-voice.bat`.
   - **macOS / Linux**: открой Терминал в папке `send-voice` и выполни:
     ```bash
     chmod +x send-voice.sh
     ./send-voice.sh
     ```
2. Открой `config.txt` в любом текстовом редакторе (Блокнот, TextEdit, nano) и заполни:
   ```
   TOKEN=123456789:AAH...твой_токен
   CHAT_ID=128697674
   ```
3. Сохрани файл. Он уже добавлен в `.gitignore` и не попадёт в git.

### 5. Использование

1. Скачай голосовое кнопкой «Скачать» в Telegram Web (сохранится файл `voice_Автор_ЧЧ-ММ.ogg`).
2. Отправь файлы:
   - **Windows**: перетащи один или сразу несколько `.ogg` файлов на `send-voice.bat`.
   - **macOS / Linux**: передай файлы скрипту в Терминале. Путь к файлу можно не печатать, а перетащить файл из Finder или файлового менеджера в окно Терминала.
     ```bash
     ./send-voice.sh ~/Downloads/voice_Автор_20-40.ogg
     ./send-voice.sh ~/Downloads/voice_*.ogg
     ```
3. Для каждого файла скрипт напишет `OK`, а в чате с ботом придут голосовые.
4. Перешли голосовое куда нужно. Чтобы не было подписи «Переслано от бота», в меню пересылки включи **«Скрыть имя отправителя»**.

### Отправка в канал (вместо личного чата)

Создай канал (можно приватный), добавь бота в администраторы с правом публиковать сообщения и укажи в `config.txt` `CHAT_ID=@имя_канала`. У приватного канала нет @имени, поэтому нужен его числовой id: он начинается с `-100`, его можно посмотреть, например, переслав пост из канала в [@userinfobot](https://t.me/userinfobot).

### Частые ошибки

| Ошибка | Что делать |
|---|---|
| `Unauthorized` | Неверный `TOKEN` в `config.txt`, скопируй его из BotFather ещё раз |
| `chat not found` | Ты не нажал Start в чате с ботом, или неверный `CHAT_ID` |
| `VOICE_MESSAGES_FORBIDDEN` | Добавь бота в исключения для голосовых (шаг 3) |
| `Заполни TOKEN и CHAT_ID` | В `config.txt` пустые значения |
| `Permission denied` (macOS / Linux) | Выполни `chmod +x send-voice.sh` в папке `send-voice` |
