# TG Media Downloader

Расширение для Chrome/Edge, которое добавляет кнопку «Скачать» под фото, видео и кружочками в [Telegram Web A](https://web.telegram.org/a/).

## Установка

1. Скачай этот репозиторий: кнопка **Code → Download ZIP**, распакуй в любую папку
2. Открой в браузере `chrome://extensions/` (или `edge://extensions/`)
3. Включи **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажми **«Загрузить распакованное»** и выбери распакованную папку
5. Открой [web.telegram.org/a/](https://web.telegram.org/a/) — под медиа появятся кнопки «Скачать»

## Обновление

Скачай новый ZIP, замени файлы в папке, затем в `chrome://extensions/` нажми иконку обновления на карточке расширения и обнови страницу Telegram.
